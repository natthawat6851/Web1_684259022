แบบฝึกปฏิบัติ: HTML Formatting

เรียนรู้การจัดรูปแบบข้อความด้วยแท็ก HTML พร้อมตัวอย่างและการตกแต่งด้วย CSS

🖥 ตัวอย่างผลลัพธ์
B: ข้อความตัวหนา
STRONG: ข้อความสำคัญ
I: ข้อความตัวเอียง
U: ขีดเส้นใต้
MARK: ข้อความเน้น
SMALL: ข้อความเล็ก
DEL: ข้อความถูกลบ
SUP: X2
SUB: H2O
</> ตัวอย่างโค้ด HTML 
1 <b>ข้อความตัวหนา</b>
2 <strong>ข้อความสำคัญ</strong>
3 <i>ข้อความตัวเอียง</i>
4 <em>ข้อความเน้นเสียง</em>
5 <u>ข้อความขีดเส้นใต้</u>
6 <mark>ข้อความที่ถูกเน้น</mark>
7 <small>ข้อความขนาดเล็ก</small>
8 <del>ข้อความที่ถูกลบ</del>
9 X<sup>2</sup>
10H<sub>2</sub>O
🎯กิจกรรมฝึกปฏิบัติ
  • ✓ ให้นักศึกษาสร้างหน้าเว็บ 1 หน้า
  • ✓ ใช้แท็ก formatting อย่างน้อย 6 รูปแบบ
  • ✓ ทดลองเปรียบเทียบ <b> กับ <strong> และ <i> กับ <em>
  • ✓ ปรับสี ขนาด และเพิ่มเงาข้อความด้วย CSS
  • ✓ บันทึกไฟล์ชื่อ formatting.html
💡

เกร็ดความรู้

แท็กที่ใช้รูปแบบข้อความช่วยให้เนื้อหาสื่อสารชัดเจนและมีความหมายมากขึ้น เช่น <strong> ใช้สำหรับข้อความสำคัญ <em> ใช้เน้นความสำคัญหรืออารมณ์ และ <mark> ใช้เน้นข้อความที่ต้องการให้โดดเด่น แท็กเหล่านี้ช่วยเพิ่มความอ่านง่ายและช่วยให้ผู้อ่านเข้าใจได้ดียิ่งขึ้น
